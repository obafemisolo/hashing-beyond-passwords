# Publish this project to GitHub

The suggested repository name is:

```text
spring-boot-hashing-beyond-passwords
```

After creating an empty repository under your GitHub account, run these commands from the project directory:

```bash
git init
git add .
git commit -m "Add Spring Boot hashing examples"
git branch -M main
git remote add origin git@github.com:obafemisolo/spring-boot-hashing-beyond-passwords.git
git push -u origin main
```

HTTPS remote alternative:

```bash
git remote add origin https://github.com/obafemisolo/spring-boot-hashing-beyond-passwords.git
```

Then replace the placeholder in the LinkedIn post with:

```text
https://github.com/obafemisolo/spring-boot-hashing-beyond-passwords
```
